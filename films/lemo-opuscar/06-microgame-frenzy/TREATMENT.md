# CAPTION FRENZY — Treatment

A Microgame Frenzy film for CapsEasy. 16.959 s (~17 s), 1080×1920 (9:16), 24 fps, no voiceover. All art drawn in code (canvas 2D), all music/foley synthesized.

## 1. Logline and arc

**Logline:** A gold stopwatch host runs three rapid-fire captioning microgames for a helmeted cadet; a greedy upload cloud steals round three and costs a life, but in the boss stage the cadet slams the big red button, renders everything locally, and stamps the cloud "0 BYTES UPLOADED."

**Arc:** Cold open inside game 1 (TRANSCRIBE!, hook in frame 1) → ✓ → game 2 (STYLE!) → ✓ → game 3 (RENDER!) → the cloud sucks the footage up, ✗, lose a life (tension) → SPEED UP slot reels → BOSS (POST!): tiles rain, breath, button slam, the cloud's hose tied in a knot, "0 BYTES UPLOADED" stamp → WIN (reveal) → end: hero salutes on the home stage, camera pushes into the TV for the end card: "stop timing captions. start posting." (CTA).

## 2. Benchmark

**WarioWare series — grammar only** (never its name, characters, UI, microgames or music).

- **Learn:** the command word is script, subtitle and downbeat at once; each microgame in a different medium (the style switch is the joke and the beat); lives-as-UI carries emotion with no narration; one unified transition grammar (here: the TV frame); failure is *performed*, not just shown; speed-up via slot reels; the boss reuses the film's own past.
- **NOT take:** any names, characters, UI designs, games, or music from it. Our host is an original gold stopwatch; our hero is an original 2.3-head cadet; our games are TRANSCRIBE! / STYLE! / RENDER! / POST!; our failure is a cloud that wants your footage.

## 7. Subtitle / title / command-word design

- **Command words** (Titan One, white fill, 22 px ink outline, lavender `#f0d7ff` starburst behind, −6° skew): slam in over 3 frames (1.9 → 0.92 → 1.0 with overshoot), hold, then shrink into a corner tag before the action so results are never covered. One-off banners ("BOSS STAGE!") fly out instead of becoming tags.
- **The command word IS the subtitle**: listed in the .srt, not burned twice. Command cues: TRANSCRIBE! (0.00–0.90), STYLE! (4.00–4.90), RENDER! (7.00–7.90), POST! (12.459–13.36), end-card line "stop timing captions. start posting." (16.234–16.959).
- **No other dialogue** (no voiceover — a TTS fetch for shouted 0.2 s commands risks the "Pompey"/"Zipper" mishearing trap in STYLE.md §8; bad VO is worse than none). The brass stab is the shout.
- **Stamps**: ✓ = deep-green circle, cream "OK!"; ✗ = ink-red circle, cream X; "0 BYTES UPLOADED" = deep-green circle, two lines, cream Titan. All pop with anticipation+overshoot+settle.
- **Lives board**: three "cc" caption tiles (gold rounded tiles, ink "cc"); the lost one cracks with ink crack lines, falls, fades — glass crack + bouncing clinks.
- **End card** (inside the TV): "CAPTION FRENZY" (Titan, gold), "stop timing captions. start posting." (Lilita, cream), "free · open-source · renders on your machine" (Lilita, lavender). No LemoLab card (user film), no watermark.

## 9. Ishaan's hard constraints (Sep 29, 2026) — applied

1. **No AI slop**: no purple-blue glowing gradients (sunburst = hard-edged flat cream/lavender rays, no glow), no floating particles/bokeh (only minimal WIN confetti as game-show grammar), no filler copy (every line is a verified fact or a command word), no stock clichés.
2. **Sharper content**: every beat advances hook → tension → reveal → CTA; one gag per game; nothing redundant.
3. **Zero overlapping**: command tags live top-right, never over action; stamps land clear of the command tag; fuse along the bottom at y=1800 (clear of phone UI); subtitle/end-card text never over the subject; every scene checked in frame review before sign-off.
