# Footage

Drop your screen recordings here. These get composited into the launch film and cutdowns.

## What to record

The real CapsEasy studio UI, clean and deliberate:

1. `01-upload.mp4` - dropping a video file into the studio, upload in progress
2. `02-transcript.mp4` - Whisper word-timestamps appearing on the transcript
3. `03-looks.mp4` - flipping through caption looks on the same clip (2-3 looks minimum)
4. `04-export.mp4` - the export flow, MP4 + SRT coming out
5. `05-hero.mp4` - your single best 5-10 second moment, anything that makes you grin

Record at 1080p or higher. Slow down your mouse. Pause half a beat before and after each action so we have handles to cut on.

## Rules

- MP4 (H.264) only. Keep each file under 100 MB (GitHub hard limit).
- Name files as above so the edit can find them blind.
- No cursor chaos, no notification popups, no other tabs visible. Full-screen the studio.
- Renders of the finished film do NOT live here. They go to GitHub Releases.
