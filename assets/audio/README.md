# Audio

Music and sound design for the launch films. See SOURCES.md for the full
research (where to get more, and the redistribution rule). See LICENSES.md
for the license on every committed file.

- `music/` — committed tracks, all redistribution-safe (CC0 or CC-BY with credit).
- `sfx/` — committed sound effects, CC0.
- Pixabay / Mixkit / Sonniss / Uppbeat / YouTube Audio Library downloads live
  on local disk only and are used in renders; their licenses forbid committing
  the raw files to this public repo.
- Keep individual files under 100 MB. Name new files with source and mood:
  `kevin-macleod_Inspired.mp3`, `pixabay_cinematic-whoosh.mp3`.
- Normalize finished mixes to about -14 LUFS.
