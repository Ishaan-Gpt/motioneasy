# Audio

Music and sound design sources for the launch film.

- Put licensed tracks here as `.mp3` or `.wav` (keep under 100 MB per file).
- Only use tracks we have the rights to (Uppbeat, Pixabay, or original).
- Name with the mood: `uplifting-120bpm.mp3`, `cinematic-swell.wav`, etc.
- The final mix is built during production. Stems welcome if you have them.
